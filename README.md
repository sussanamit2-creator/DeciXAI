# דוח מכין – מצפן ספקים

סמינריון מחקרי בניהול טכנולוגיות (5523001), אוניברסיטת בר-אילן, תשפ"ז.
מגישות: טל אזואלוס ועמית סוסן. מנחה אקדמי: ד"ר יורם סגל. מנחה תעשייתי: מר מירום לוין, התעשייה האווירית לישראל.

**הדוח עצמו:** [`דוח מכין - קובץ ראשי/main.pdf`](דוח%20מכין%20-%20קובץ%20ראשי/main.pdf)

## מבנה התיקייה

| תיקייה / קובץ | מה יש בה |
|---|---|
| `דוח מכין - קובץ ראשי/main.tex` | הקובץ הראשי: מחבר את כל הפרקים |
| `דוח מכין - קובץ ראשי/template.cls` | התבנית: כל העיצוב (גופנים, שוליים, כיוון עברית-אנגלית, טבלאות, איורים) |
| `עמוד שער ותקציר/` | שער, תקציר, רשימת קיצורים ולוגואים |
| `פרק 1 - מבוא/` … `פרק 8 - סיכום/` | קובץ `.tex` לכל פרק; האיורים נבנים בקוד TikZ/pgfplots בתוך הפרק |
| `מקורות/references.tex` | רשימת המקורות (IEEE, לפי סדר ההופעה) |
| `דוחות צוות אדום/` | דוחות הביקורת של הצוות האדום ("ועדת המומחים") |
| `ביקורת צוות אדום/` | התשובות שלנו לדוחות הביקורת, וביקורת פנימית ראשונה (לא חלק מהדוח) |
